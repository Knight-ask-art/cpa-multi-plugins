凭据状态 dual-cred

一个账号有两套凭据：plan JWT（走 zcode.z.ai 的 anthropic 网关）和 coding-plan API key（走 api.z.ai / bigmodel）。两边是各自独立的上游，坏了一个不影响另一个。这里显示哪一边被暂时停用、为什么、还有多久恢复。状态存在插件进程内存里，重启清零。
